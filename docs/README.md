# Documentation

| File | What it covers |
|---|---|
| `failures-this-avoids.md` | the ways an options agent goes wrong, and what this one does instead - each with the file where it can be checked |
| `slides.pdf` | the deck: what it does, what each control stops and what it does not, and the account it is judged on |
| `account-evidence/` | the five answers behind every number this project publishes about its own trading, downloaded and committed, checkable with no network |
| `api.md` | the five read routes anyone can query, what each answers, and the command that checks the account against these documents |
| `algorithm.md` | how a trade is decided, end to end: what wakes the agent, how a structure is found and measured, how it is sized, filled and left, and what each control can and cannot stop |
| `capabilities.md` | every capability the system has, where it lives, and the command or test that shows it works |
| `write-up.md` | the one-page write-up required by the hackathon: agent logic, risk gates, Alpaca infrastructure |
| `architecture.md` | how the pieces fit together and why |
| `deploy.md` | how to run the stack on a server: what it needs, how to start it, how to update it |
