# Токены Haia

Скопированы из `Haia-Finance/haia-design-system`, слой сырых значений
(`tokens.css`) и слой ролей (`semantic.css`). **Правятся там, а не здесь**: если
понадобится изменить значение, меняется в системе и переносится сюда целиком.

Почему скопированы, а не подключены пакетом: система отдаётся файлами CSS без
пакета npm, а репозиторий закрыт. Тянуть закрытый репозиторий на сборке значило
бы завести на неё ещё один ключ и ещё одну причину упасть.

Наше расширение лежит НЕ здесь, а в `../style.css`, отдельным блоком с подписью.
Так видно, где кончается система и начинается наше.
